The director (pbz-roguelike.exe) and the in-game bridge exchange files in this folder, and the
director keeps the run save and your profile here. Nothing in it is a game file.

inbox.tsv     the director's current command
state.tsv     what the bridge sees in the game
run.json      the run in progress
profile.json  your record across runs
bridge.log    the bridge's log
director.log  the director's log

Deleting everything but this file resets the mod.
